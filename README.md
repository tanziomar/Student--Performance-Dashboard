Student Achievement & Attendance Dashboard

This repository includes a Power BI dashboard I created to explore student performance and attendance trends for the NJTC tutoring program. The goal of the project is to understand how much students improved over time and whether consistent attendance played a role in their progress.

## About the Dashboard

The dashboard focuses on a few key areas:

- **Overall improvement** across all students  
- **Improvement by grade level** (Grades 3–5)  
- **Relationship between attendance and improvement**  
- **Comparison of pre-test and post-test scores**  

The goal is to provide a clear and simple view of student progress during the tutoring sessions.

---

## Why I Created This

I built this dashboard as part of my experience with NJTC, where I helped track student performance and engagement. I wanted a straightforward way to see whether the tutoring sessions were making a measurable difference for students.

By comparing pre-test and post-test scores and looking at attendance patterns, the dashboard highlights which students are improving, which grade levels may need more support, and how consistent attendance affects academic progress.

This project also allowed me to practice key Power BI skills—data cleaning, creating visuals, writing basic DAX measures, and designing a dashboard that tells a meaningful story. My goal was to create something useful for the tutoring program while also showcasing the type of analytical work I can do.
